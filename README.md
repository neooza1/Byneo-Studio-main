# BYNEO STUDIO

> Digital experiences for businesses whose reputation deserves a stronger online presence.

ByNeo Studio is a digital design studio focused on building thoughtful websites, digital experiences and visual systems for established businesses.

This repository contains the ongoing development of the ByNeo Studio website and digital studio system.

---

## CURRENT STATUS

 **REBUILD IN PROGRESS**

The ByNeo website is currently being rebuilt as part of a broader studio rebrand.

The public site is intentionally being kept minimal while the new identity, website system, portfolio and client work are developed in private.

The current direction focuses on:

- Stronger digital positioning
- Premium web experiences
- Better storytelling
- Case-study driven portfolio presentation
- Clearer customer journeys
- Technical quality
- Design systems that can scale

---

## POSITIONING

ByNeo is moving beyond simply offering "web design."
